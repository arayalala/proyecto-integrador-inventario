## 2. Objetivo del Sistema
Desarrollar una solución informática funcional en Python que permita gestionar el registro, cálculo de stock financiero y búsqueda de artículos, aplicando estructuras lógicas condicionales, bucles repetitivos y programación modular sin utilizar la función `main`.

## 3. Descripción de Funcionalidades
1. **Registrar Producto:** Captura el nombre del artículo y realiza validaciones estrictas mediante bucles y control de excepciones (`try/except`) para asegurar que el precio sea mayor a cero y el stock no negativo.
2. **Ver Inventario Completo:** Recorre la colección de datos almacenada en memoria, calcula subtotales por producto y consolida el valor financiero total del inventario.
3. **Buscar Producto:** Permite realizar búsquedas interactivas por nombre para consultar el precio y las existencias exactas de un artículo.
4. **Salir del Programa:** Finaliza de manera limpia y controlada la ejecución del bucle interactivo de la consola.

## 4. Estructura del Repositorio y Arquitectura
* **`/src`**: Contiene el código fuente completo del programa en Python (`main.py`), estructurado en funciones modulares.
* **`/docs`**: Contiene los diagramas desarrollados del sistema.
